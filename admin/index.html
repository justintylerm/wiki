One-time setup

1. Create a GitHub token: under Repository access choose Only select repositories → wiki, then under Permissions → Repository permissions set Contents to Read and write. Click Generate and copy it.

2. Paste it here and choose your password. The token is encrypted with the password, so from then on the password is all you need.
